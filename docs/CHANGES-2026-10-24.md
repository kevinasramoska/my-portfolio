## Verification flow

timeline through full-time judo, inspects RentRight's current evidence, and opens
the matching resume.

Content flows from shared JSON/TypeScript into static server-rendered pages and
the generated HTML/PDF. There is no portfolio database or mutation API to test.
Browser checks cover navigation, visible content, image/PDF responses, metadata,
mobile keyboard navigation, overflow, console errors, and automated axe scans.
The React review preserved server components, stable list keys, semantic content,
optimized local images, and no new dependency/client-side fetching.
